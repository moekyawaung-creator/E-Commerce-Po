# 🛒 ECommerce Pro
**Premium Android E-Commerce App** | MVVM + Clean Architecture + Jetpack Compose

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## ✨ Features
✅ **Jetpack Compose UI** - Modern Material 3 Design  
✅ **Clean Architecture** - MVVM + UseCases + Repository  
✅ **Hilt DI** - Professional Dependency Injection  
✅ **Room Database** - Offline Shopping Cart  
✅ **Retrofit + Coroutines** - API Integration  
✅ **Firebase Auth** - Google/Email Login  
✅ **Stripe Payments** - Real Payment Integration  
✅ **Push Notifications** - FCM
